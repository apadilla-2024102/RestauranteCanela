# RestauranteCanela

Sistema backend para la gestión integral de un restaurante desarrollado mediante una arquitectura de microservicios.

---

## 📌 Descripción

**Restaurante Canela** es una plataforma diseñada para administrar las principales operaciones de un restaurante, permitiendo gestionar usuarios, menús, inventario, pedidos, pagos, reservas y reportes.

El proyecto está organizado en forma de **microservicios**, lo que facilita su mantenimiento, escalabilidad y desarrollo independiente de cada módulo.

---

## 🏗️ Arquitectura

El sistema está compuesto por los siguientes microservicios:

- 🔐 Auth Service (Autenticación y autorización)
- 👤 Client User Service (Gestión de clientes y usuarios)
- 🍽️ Menu Inventory Service (Menú e inventario)
- 🛒 Order Service (Pedidos)
- 💳 Payment Service (Pagos)
- 📅 Reservation Service (Reservas)
- 📊 Report Service (Reportes)
- 🏢 Restaurant Service (Administración general)
